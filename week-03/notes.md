## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

```
The difference between a file and a folder is that a file is just one stored item whereas a folder is multiple files contained in a direct place. Files and folders form a tree structure because everything starts from a single root and branches outward. This creates a hierarchy where folders can contain files and other folders, which can branch out even further from the root. 
```

**How does a Windows-style file path differ from a Linux-style file path?**

```
A Linux-style path starts from one root, uses forward slashes and does not have drive letters. In contrast a Window-style path uses drive letters such as C:, and backslashes to separate directories.  
```
